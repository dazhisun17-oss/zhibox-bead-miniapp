# 智宝箱：拼豆微信小程序核心代码

这是已上线微信小程序“智宝箱”的脱敏作品集版本。项目在约 1.5 个月集中运营期间累计获得 1,945 名用户，其中 33 名用户添加了小程序。

仓库重点公开拼豆生成与识图的核心引擎、编辑器关键交互和自动化回归测试。微信 AppID、云环境标识、服务密钥、本机配置、用户数据和运营素材均未包含。

## 核心能力

- 将照片转换为有限色卡的拼豆图纸
- RGB 到 Lab 的感知颜色匹配，以及少色/丰富色模式
- 主体背景识别、轮廓保护、色块合并和噪点清理
- 已有拼豆图纸识别、二维码结构分析和材料数量统计
- 拼豆编辑器的缩放、拖动、绘制、历史记录与导出流程
- PNG、PDF、CSV 等导出链路的兼容性处理

## 质量验证

保留的回归脚本覆盖：

- 32 / 52 / 78 / 104 格生成结果与色卡约束
- 少色模式和丰富模式的一致性
- 二维码、黑白结构和关键细节保护
- 已有图纸识别与色块解析
- Android / iPhone 图片路径和格式兼容
- 编辑器手势与关键交互契约

## 运行核心测试

```bash
cd apps/wechat/miniprogram
npm install
npm run test:showcase
```

## 目录

```text
apps/wechat/miniprogram/utils/         拼豆算法、识图和文件兼容工具
apps/wechat/miniprogram/data/          脱敏色卡数据
apps/wechat/miniprogram/pages/beads/   拼豆编辑器核心页面
scripts/                               可独立运行的回归测试
```

该仓库是用于代码审阅的精选版本，不是包含微信云开发配置的完整生产仓库。
